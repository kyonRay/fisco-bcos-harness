# ADR-0002: 腾讯智能表格为需求状态真相源，GitHub 为镜像，动作嵌入式同步

Status: accepted
Date: 2026-08-20

## Context

子需求、认领人、完成勾选等状态可能同时存在腾讯智能表格和 GitHub 两处，必有一处
是镜像。且本机 skill 形态下没有常驻进程监听 GitHub webhook，镜像同步需要明确时机。

## Decision

1. **腾讯智能表格是唯一真相源**：需求拆分、认领、进度、完成勾选都在表格；
   GitHub 上的 PR/issue 状态是镜像视图。
2. **动作嵌入式同步**：每个改变状态的工作流动作（建 PR、发 review、合入、跑门禁）
   对应的 skill 在动作尾部顺带回写表格对应行。状态变更者负责写回，无轮询、
   无 webhook。

## Consequences

- 表格实时性取决于大家都通过 harness skill 执行动作；绕过 skill 手工操作 GitHub
  会造成镜像滞后。催办/standup 命令可顺带对账兜底（后续如发现漏写严重再加）。
- 每个 skill 都要能访问腾讯文档 API（凭证分发见后续 ADR）。
- 智能表格自动提醒（@认领人）作为表格侧的原生触达通道，与企微定向@并用。
